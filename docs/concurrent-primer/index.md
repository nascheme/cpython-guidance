# Concurrent Programming Primer, for CPython Developers

This primer explains concurrent C programming and the mechanisms used by
free-threaded CPython. Chapters 1–8 cover general concepts, chapters 9–13 cover
CPython, and chapter 14 helps you choose a technique.

Start with [shared mutable memory](01-shared-mutable-memory.md), or use the
[contents and topic index](contents.md) to find a specific subject.
